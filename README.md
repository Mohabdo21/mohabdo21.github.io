mohabdo21.github.io

My portfolio site. Static HTML, CSS and one small script, served by GitHub Pages.
Nothing to build, nothing to install, no third-party requests.

Layout:

- `index.html` - the whole site, one page, anchored sections
- `style.css` - design tokens and layout, light and dark
- `script.js` - theme choice, mobile section menu, rail current-section
- `style.min.css`, `script.min.js` - what `index.html` loads, generated by esbuild
- `fonts/` - self-hosted IBM Plex (Sans, Sans Condensed, Mono), latin subset
- `favicon.svg`
- `og.png` - 1200x630 link preview card

The `.min` files are built artifacts and are regenerated by a pre-commit hook,
so never edit them by hand. On a fresh clone, enable the hook once:

```sh
git config core.hooksPath .githooks
```

The theme follows the OS preference until a reader picks one, which is stored
in `localStorage`.
